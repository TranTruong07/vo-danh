# THƯ MỤC CHỨA TÀI LIỆU PDF

Bạn hãy copy/paste các file PDF của mình vào thư mục này (`data/documents/`).

Chatbot sẽ tự động đọc tất cả các file PDF trong thư mục này và dùng nó làm cơ sở dữ liệu duy nhất (Strict Grounding) để trả lời người dùng.
- Chatbot chỉ trả lời các thông tin có trong các file PDF ở đây.
- Nếu người dùng hỏi điều gì không có trong tài liệu, Chatbot sẽ từ chối trả lời theo đúng yêu cầu.
